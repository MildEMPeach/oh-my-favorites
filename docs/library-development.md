# 网页收集与收藏开发范围

## 核心流程

网页入库 → 稍后消费 → 收藏 → 笔记与标签整理。

- Collected / Unread：URL 收集、已读状态、内嵌阅读、默认浏览器打开、批量操作。
- Favorites：同一网页条目标记收藏，支持笔记、分类、内容日期和搜索；新增收藏需要网页 URL。
- Tags：标签关联到条目，侧栏跨收集与收藏浏览；收藏内可组合分类和标签筛选。
- Telegram、浏览器扩展、MCP：继续使用同一份服务端数据。

## 数据与兼容

保留旧条目的 ID、标题、URL、阅读状态、收藏、笔记和标签。旧库的 URL 可空兼容保留，已有无网址笔记仍可编辑。

移除扩展功能的界面、接口、桌面 IPC 和共享类型。已有数据库的扩展表、旧列和记录不删除；仅将支持的条目区域公开给应用。新数据库只创建核心表和字段。实际升级前备份 SQLite，更新后核对条目、标签及历史数据。

## 验证

覆盖旧库升级、历史数据隔离与保留、网页收藏输入校验、标签跨视图查询、默认浏览器安全边界、草稿保护；执行全仓库测试、类型检查和构建。
